Selecting Sensors

When selecting sensors, certain sensors are incompatible with each other due to conflicting pin usage.

The PCAP02 should not be enabled with the YFS210C. (GPIO A10 is used as an external interrupt by both sensors.)

The SEN0308 should not be enabled with either Voltage or Current. (SEN0308 outputs an analog voltage which is read by the onboard ADC.)

Select sensors starting from the lowest number available. For example, do not leave Sensor 1 as "none" and select Sensor 2 as "Teros12". Instead, make sure that all selected sensors are packed towards Sensor 1.

Cell ID: You may leave the Cell ID field blank to use the Default Cell ID you entered at the top of the page.

Index: The index field is typically used to specify the sensor address, such as when multiple of the same sensors are used on the same bus in order to avoid addressing conflicts.

  • For SDI-12 sensors, you may enter either the ASCII character of the device address (i.e. 'a', '0', 'N' without quotes) or leave blank to use the default '0' address. Valid SDI-12 addresses: ['0'-'9'=48-57, 'A'-'Z'=65-90, 'a'-'z'=97-122].
  • For I2C sensors, leave blank to use the default sensor address, or enter the non left-shifted 7-bit address in decimal. Non-decimal input (such as hexadecimal) is not supported.
  • For onboard analog sensing (such as the Irrometer Watermark 200SS), you may enter either the ADC channel number or leave blank to use the default ADC channel.
  • For digital sensors (such as pulse output water meters or frequency/PWM output flow meters), you may enter either the pin number or leave blank to use the default pin.
ADS1219 Voltage and Current Calibration

For best effect, use the calibration values obtained during the analog to digital converter (ADC) calibration process: https://github.com/jlab-sensing/ENTS-node-firmware/blob/main/docs/first-time-setup.md

You may leave these values blank (or 1, 0, 1, 0 to configure the ADC to output its raw measurements when enabled) if you do not intend on using the onboard ADC to take voltage and current readings.

Values may be entered in scientific notation (e.g. 1.23e-5).

If you only need a ballpark reading, then you may use these typical calibration values (Vm, Vb, Im, Ib):

-0.00039358

-0.00566470

-1.18688004e-10

3.94985336e-5
